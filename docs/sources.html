H46-1 · InSAR availability

NASA OPERA DISP-S1

NASA/JPL's Level-3 OPERA DISP-S1 is a time-series LOS displacement product with 30 m posting. NASA CMR returned online-accessible granules overlapping parts of the broad area, including a central-strip granule spanning 2025-09-17 to 2025-09-23. The sample records demonstrate partial-area availability only; full grid tiling, valid observation count, data quality, and the file payload have not been checked.

Dataset DOI ↗ · CMR query: central-area records ↗ · CMR query: broad rectangle ↗

No OPERA payload was downloaded. NASA's catalogue says products are openly shared; preserve citation and product metadata. Earthdata account/access requirements must be followed.

H46-1 · raw-SLC availability check

Copernicus Sentinel-1C SLC

The documented broad-area OData query returned S1A-only catalog products. It did not establish a repeat-pass pair, S1C/S1D coverage, payload access, complete AOI coverage, or raw-SLC/InSAR feasibility. Sentinel-1A operations ended 2026-06-29; the mission transition alone is not evidence that a suitable current repeat pair covers this grid. No SLC files, baselines, coherence, or interferograms were inspected.

Official Sentinel-1 collection ↗ · OData docs ↗ · ESA mission transition ↗

Sentinel data are free/open with required source and modified-data attribution. Copernicus Data Space registration is required for data access. Data licensing does not waive the competition's independent-verification/sharing requirements.

H46-2 · hydrology availability

USGS Water Data APIs

The modern `field-measurements` API returned example groundwater-level records with locations inside the broad rectangle. The `monitoring-locations` API returned groundwater wells there. This demonstrates some data presence, not dense coverage; returned readings span different dates/vertical datums and include multiple agencies.

Field-measurement sample query ↗ · Groundwater-site query ↗ · USGS migration guide ↗

The legacy `/gwlevels` API was decommissioned; use modern `/field-measurements`. Check agency, aquifer, datum, time, well depth, pumping, and spatial support before inference.

H46-3 · alteration availability

USGS ASTER-derived maps

A USGS CC0 release maps hydrothermal alteration types/mineral groups across the northwestern conterminous United States. A second USGS release covers central/southern Basin-and-Range plates. Neither was overlaid with the official grid in this session, and a prior owner-reported `conj_alteration_mag` test may overlap.

2017 western-U.S. data release ↗ · Basin-and-Range report ↗ · ASTER SWIR limitation ↗

ASTER SWIR observations acquired since April 2008 are unusable. Verify per-pixel acquisition dates, valid bands, registration, and exact coverage; do not equate alteration polygons with fault traces.

Scientific context

Mechanisms are supported; score gains are not.

Primary/official work motivates the hypotheses, but none establishes performance on the hidden challenge labels.

USGS InSAR fact sheet: concealed fault and groundwater barrier ↗

USGS describes linear groundwater barriers in interferograms and a previously unrecognized Santa Clara Valley fault later confirmed by seismic imaging. It also warns pumping deformation may mimic or obscure tectonic signals.

Amelung et al. (1999): fault control of Las Vegas subsidence ↗

InSAR-derived subsidence was spatially controlled by geologic structures and sediment composition. This is a regional analogue, not proof of new-fault detection in GEMS.

Hose & Taylor (1974): northern Nevada geothermal systems ↗

USGS discusses hot springs along Basin-and-Range faults and meteoric-fluid circulation. This supports geological rationale, not a model score.

Faulds et al. (2025): Reese River Valley / INGENIOUS ↗

Recent USGS work discusses fault intersections, concealed geothermal potential, and subtle anomalies in north-central Nevada. Review labels, provenance, and leakage before using related material as an independent test.

Romaguera et al. (2018): geothermal LST component ↗

USGS Publications Warehouse record describes topographic false positives and uncertainty in thermal remote-sensing estimates; terrain correction is essential.
