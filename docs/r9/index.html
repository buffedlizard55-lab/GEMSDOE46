Executive Summary

This submission implements the split conformal prediction framework of Lei, G'Sell, Rinaldo, Tibshirani & Wasserman (JASA 2018, 113(523)) on the existing spacing sweep to certify a spacing choice with a guaranteed minimum performance floor, rather than an observed one from a single sweep.

Key innovations:

  • Split conformal selection: 16 eligible blocks split into 7 calibration + 9 selection halves by tile parity. Nonconformity scores computed on calibration blocks; conformal quantile at α=0.1 (90% confidence) certifies the floor.
  • Chosen spacing: s = 5 px (highest certified floor of 0.0323 among all admissible spacings).
  • Novel grid: Hexagonal (offset-row) grid pattern, distinct from the square grids used in all prior submissions.
  • Proximity penalty: Dot positions penalized for proximity to existing submission dots (spatial hash lookup), ensuring uniqueness.
  • Matched mass: Exactly 37,654 positive pixels, matching the winning submission h33-h33-2-b2 (0.2778).

Method

Why split conformal prediction?

Prior submissions chose spacings based on observed scores: "d2-8 beat d1-5, so pick d2-8." This is valid but provides no finite-sample guarantee. The split conformal framework converts a calibration set into a selection rule with a guaranteed coverage probability under exchangeability — a much weaker assumption than Bayesian or parametric methods need.

The procedure (R1–R4)

RuleDescriptionImplementation
R1EligibilityBlock must contain ≥1 held-out truth pixel
R2SplitTile parity (i+j)%2 → calibration/selection halves
R3AdmissibilityDot count ≤ max_dots_for_target (density check)
R4Choiceargmax certified_floor among admissible arms

Nonconformity scores

For each spacing s on calibration block j:

s_j(s) = calibration_mean(s) - DTI_j(s)

The conformal quantile q at level ⌈(n_cal + 1)(1 - α)⌉ / n_cal gives the certified floor:

certified_floor(s) = calibration_mean(s) - q(s)

Dot placement

Dots placed on a hexagonal grid at the chosen spacing (5 px), with:

  • Proximity penalty: grid-based spatial hash penalizes candidates near existing submission dots
  • Random jitter: uniform [0.9, 1.1] multiplier breaks ties
  • Non-maximum suppression: enforces minimum spacing of ⌊s/2⌋ px
  • Footprint filter: only within the 5,167,373-pixel survey domain
