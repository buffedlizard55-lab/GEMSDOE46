Unique artifact name

Name the method and the bytes.

The packaging tool will create a unique filename only after a passing holdout report. The expected pattern is:

gemsdoe46-{candidate-id}-{YYYYMMDD}-{10-char-prediction-hash}.tif

For example, a future H46-1 result would use a name beginning with gemsdoe46-h46-1-opera-disp-v1-. Copy the actual filename stem (everything before .tif) exactly into DrivenData's submission-name field. That stem is generated from the UTC date and probability fingerprint; it is a naming template—not an existing file or score claim. No actual submission name is assigned yet. Known prior TIFs must be supplied to the duplicate check.

Exact portal workflow

When a validated file exists

These steps follow the official competition flow. Portal labels can change; use the live competition page as the final authority.

Open official competition ↗

Enroll and sign in

Open the DOE GEMS competition page, accept the competition terms, and sign in to the authorized participant account. Do not share credentials with this repository or store them in Git.

Download the official inputs from the Data page

Use the competition's authenticated Data page. Place the downloaded ZIP in data/inbox/, then run bash scripts/download_competition_data.sh. The script imports a local archive only; it does not log in, scrape, or fetch competition files.

Verify the grid and inputs

Set up the project environment with python -m venv .venv && .venv/bin/python -m pip install -e '.[test]'. Identify the official feature, label, and sample rasters from the archive, then run .venv/bin/python scripts/validate_inputs.py --features … --labels … --sample …. Confirm EPSG:32611, 100 m resolution, identical bounds/transform, binary-label semantics, and the exact valid mask before modeling.

Require a spatial holdout win

Generate candidate and baseline out-of-fold predictions using four contiguous blocks and a 300 m label embargo. Run .venv/bin/python scripts/evaluate_holdout.py …. Continue only if the report shows a higher DTI, at least three of four block wins, comparable probability mass, and verified fold provenance.

Download the generated TIF from this site's first card

Only after packaging passes, the download control at the top of the project home will link to the unique float32 GeoTIFF. Check its hash/receipt and run .venv/bin/python scripts/validate_submission.py --submission … --sample … independently.

Upload the file on DrivenData

Return to the competition page, choose Submit Predictions (or the current equivalent in the competition navigation), select the generated .tif, and paste its exact filename stem as the submission name. Confirm the upload and wait for the organizer's format/score feedback; save the receipt and reported score next to the run record.

Choose the final submission only after review

The official rules state up to three feedback submissions per week and one selected final submission used for both rounds. Do not spend a feedback slot on an idea that has not beaten the current spatial holdout best. Recheck the live rules and deadline before final selection.
